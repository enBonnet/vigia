# AGENTS.md

## GNOME extension review

Use the `gnome-extension-review` skill (`.agents/skills/gnome-extension-review/`) whenever you review, audit, fix, or refactor the extension code in `extension/` (`extension.js`, `prefs.js`, `metadata.json`). Follow its workflow and report format, and re-run its `scripts/static_checks.py` after applying fixes.
